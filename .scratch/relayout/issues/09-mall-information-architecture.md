# 商城化：把 md3 的信息架构换成正经电商的样子

Status: done
Type: task
Blocked by: 08

店主看过 08 的左侧导航栏版本后说「就是我看到的东西都要重新排列，做成个像样子的商城」。
Material 3 的 app 式布局对一家卖卡密的店来说太像工具软件，不像商城。这张票把 md3 模板的
外壳与主要页面整体换成大家熟悉的电商信息架构，视觉仍用 md3 令牌与组件类（设计语言不变，排版变）。

## 外壳（`layout/Md3Layout.vue`，样式在 `styles/md3.css` 第 8 节）

- 桌面三段式头部：工具条（欢迎语、最新公告、登录/注册、游客查单、语言、深浅色）→
  主头部（品牌、大搜索框、我的订单、购物车角标；吸顶）→ 分类导航条（「全部分类」悬停/点击下拉
  展示一二级分类，其后是首页、商品中心、前 6 个一级分类、博客/公告/关于/自定义链接；随页滚动）。
- 手机：品牌 + 购物车 + 主题 + 菜单一行，下面一整行搜索条；底部导航四项（首页 / 分类 / 购物车 / 我的或游客查单）。
- 页脚四栏：品牌与联系方式 / 购物指南 / 帮助中心（含后台自定义链接与页脚链接）/ 服务保障；底部版权行。
- 搜索统一跳 `/products?search=`（列表模式跳首页），列表页与首页都会把 `?search=` 回填到筛选。

## 顺手修的

- 「全部分类」下拉：悬停已打开时再点击会关掉（点击改为只负责打开，Esc / 点外面 / 路由切换收起）。
- 手机「更多」菜单一点就关：图标随状态 v-if 切换，冒泡到 document 时原 svg 已卸载，`contains` 误判；改用 `composedPath`。
- 手机商品列表工具栏的搜索框被挤成 0 宽：手机独占一行。
- 详情页手机底部购买条从不出现：`onLoaded` 时购买区 DOM 还没渲染，IntersectionObserver 挂空；改为 watch 模板 ref。
- 公告列表由 `<button>` 改为真链接（可右键、可爬）。

验收：`pnpm run build`、`pnpm test`（62）通过；票 10 的全量点击测试桌面 60/60、手机 53/53。

## 补充（同日）

店主看过线上后：页面内容「很完美」，但顶部三段式太重，要「参考以前的，或者像博客一样的那种导航」。
桌面头部改回单行（64px，吸顶）：品牌 + 导航链接（首页、商品中心、一级分类不超过 3 个就全放、否则只放前 2 个并把全部一二级分类收进「更多分类」下拉、
博客/公告/关于/自定义链接；博客这些导航项优先级高于分类，不能被分类挤掉）+ 紧凑搜索框（聚焦时变宽）+ 我的订单 / 购物车 / 深浅色 / 语言图标 + 登录按钮。
工具条与「全部分类」大按钮那排删掉；手机头部与底栏不变；页脚不变。三段式的样式类留在 md3.css 第 8 节没删，以后要用直接拿。
另：配色换成蓝色（种子 #1a73e8）、品牌不再显示首字母方块、页脚不列分类，见 CUSTOM.md 对应行。
