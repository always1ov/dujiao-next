# 前台页面排版重构（md3 模板）

Status: done（2026-09-06 全部票完成；票 09/10 商城化与全量点击测试同日完成）
日期：2026-09-06。店主决定：品牌化先不搞，只做页面排版重构。

## 目标

让 md3 模板的页面组织不再逐页照搬上游（三套模板此前都是同一套信息架构），熟悉上游的人不能一眼认出；同时保持 MD3 视觉语言、全部业务逻辑复用 `composables/`、路由与 URL 不变（ADR-0002）。

## 范围

改 `frontend/user/src/templates/md3/` 下这几页的版式与信息架构；新增文案放在三种语言 JSON 的 `md3.*` 命名空间；不改 classic / vault，不改路由，不改邮件。

| 页面 | 现在（照搬上游） | 重排后 |
| --- | --- | --- |
| 首页 | 横幅 → 分类块 → 热门商品一张大网格 → 最新动态卡片 | 搜索优先的顶部区（大搜索框 + 分类 chips，右侧放横幅卡）→ 公告条 → **按分类分组的商品区**（每组一行，手机横向滑动）→ 「怎么买」三步 → 最近更新列表 |
| 商品列表 | 左侧分类栏 + 网格 + 分页 | 顶部工具栏（搜索、结果数、网格/列表切换）+ 全宽分类 chips + 网格或列表 + 分页；桌面不再有左栏 |
| 商品详情 | 左图右购买区两栏 → 描述 → 相关文章 | 全宽摘要条（分类、标题、chips）→ 左：图册 + 分页签（详情 / 购买须知 / 相关文章）；右：吸顶购买卡（价格、规格、数量、按钮、须知） |
| 购物车 | 左列表右汇总 | 单列：商品行 + 底部汇总条（桌面吸底、手机在底部导航上方） |
| 结算 | 左表单右汇总 | 单列 720px：订单摘要（可折叠）→ 联系方式与下单方式 → 优惠码 → 支付方式（单选行）→ 底部吸底提交条 |
| 支付 | 左订单信息右操作 | 顶部应付金额大卡（含倒计时）→ 支付方式 → 商品 → 底部吸底支付条；结果视图二维码居中 |
| 游客查单 | 顶部表单 + 列表 | 居中查询卡 + 结果列表 |
| 外壳（票 08） | 顶栏（品牌左、导航中、图标右）+ 四栏页脚 | 桌面左侧导航栏、无顶栏；手机搜索式应用栏 + 底部导航栏；单行页脚 |
| 外壳（票 09，替代 08） | 左侧导航栏 | 电商三段式头部（工具条 / 品牌+搜索+购物车 / 分类导航条）+ 四栏页脚；手机搜索行 + 底部导航 |
| 首页、列表、详情、购物车、结算（票 09） | 上面的 MD3 app 式版式 | 正经电商信息架构：分类面板 + 轮播 + 公告、热门与分类分区、左侧分类树、详情两栏 + 同类推荐、购物车表格 + 结算卡、结算左表单右摘要 |
| 全量点击测试（票 10） | 无 | Playwright 桌面 60 项、手机 53 项全部通过，脚本进 `docs/agents/scripts/` |

## 不做

- 不改 URL、不改邮件模板、不加品牌元素（名字、logo、配色沿用 md3 令牌）。
- 不动个人中心子面板、博客、公告、关于、条款、登录注册。

## 验收

- 三种语言无缺键；`pnpm run build` 与 `pnpm test` 通过；本地全栈截桌面与手机视图（`docs/agents/smoke-test.md`）。
- 账户入口开关关闭时，新版式里仍看不到登录与个人中心入口。
